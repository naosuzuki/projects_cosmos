COSMOS SN search — all versions

Pipeline for finding supernovae in the COSMOS field by combining HST ACS, JWST NIRCam, and Euclid (VIS + NISP) imaging. Each version is a different detection method. Latest version on top.

v05 — Synthetic-injection CNN latest CNN attempt

38,993 candidates · recovered 1/17 known SNe in-sky · limited: CNN over-fires on hosts
Per-survey CNNs retrained with thousands of synthetic SN injections (Gaussian PSFs at random sky positions, dN/dm-distributed magnitudes) instead of just rotating the 17 real SNe like v03. Thresholds set to 80% LOO recall. Same 1-of-3 telescope rule (HST / JWST / Euclid, where Euclid = VIS or NISP). The bigger training set let the LOO test reach 17/17 HST recall, but in-sky recovery is still 1/17 — the CNN fires on persistent host galaxies in every survey, so real SNe trip the 1-of-3 rule. The single-epoch photometry can't tell a SN+host from a host alone.

v04 — Difference imaging validated on known SNe

424,577 candidates @ ≥5σ · per-band residual SNR up to 1163 on known SNe · isolates real transients
Pixel-level difference imaging: for each candidate, take HST F814W (2005-2008, pre-dates JWST/Euclid epochs) as a SN-free template, reproject onto the science image's WCS, PSF-match and scale to the local annulus, then subtract. A real modern-epoch transient leaves a strong positive residual at the catalogue position in JWST or Euclid bands; persistent hosts cancel out. Validated on the 17 known SNe: most have per-band residual SNR ~10-1000 (e.g. SN 78323: H-band 1163σ), HST SNe correctly absent (they're in the template). Detection rule: ≥2 of 4 JWST bands ≥5σ OR (Euclid VIS ≥5σ or ≥2 of 3 NISP bands ≥5σ). The 5σ threshold currently lets ~85% of sources through (residuals from imperfect PSF matching) — tuning the threshold up to ~15-20σ would keep all known SNe and cut FPs dramatically.

v03 — Per-survey CNN, corrected labels first principled CNN pipeline

112,399 candidates · recovered 1/17 known SNe in-sky · CNN learnt host morphology, not transients
First version built against the cleaned master catalogue (master_or_catalog_v03.parquet: 1.21M rows, after removing Gaia stars / AGN / PM-significant / saturated sources). Per-survey CNNs trained on the discovery-telescope SNe (HST: 3, JWST: 13, NISP: 1) with rotation + magnitude-scaled augmentation; FPR=10−3 threshold. 1-of-3 telescope rule (HST / JWST / Euclid). Discovered the fundamental limitation: the CNN learns "compact source on a host" rather than the transient signature, and the 1-of-3 rule then rejects real SNe because their hosts trip the CNN in every survey. Same dataset, same rules — different result from v05 because v05 has bigger/more independent positives, but the same in-sky pathology.

v01 — Original baseline superseded

4,960 candidates · labelling bug
First end-to-end pipeline against the pre-v03 master catalogue. Labelling bug: all 17 known SNe were marked positive in every survey (rather than only their discovery telescope), so the CNN learned "any compact source = SN" for every survey. Top candidates were dominated by host-galaxy false positives. This discovery is what motivated v03's per-discovery-telescope label scheme and the upstream master-catalogue cleanup (programs_star v02 → v03).
