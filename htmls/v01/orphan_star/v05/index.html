Star orphans v05 — strict 3-mission rule + JWST chip-gap check

Rules:

  1. Must have a JWST F115W detection (JWST ID is the canonical identifier). No JWST → disqualified.
  2. Must have HST F814W and Euclid VIS cross-matches.
  3. JWST pixel coverage ≥ 80% in 5×5 around the position (removes chip-gap detections).
  4. HST F814W image extent: FWHM ≤ 0.214″ AND ellip ≤ 0.3.
  5. Catalog galaxy veto (Euclid PHZ, HST mu_class, CW flag_star, COSMOS2020 lp_type).
