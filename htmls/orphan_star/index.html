Orphan-star project

Versions of the orphan-star candidate decks. Each version is a snapshot so we can compare progress across analysis revisions.

v01   built 2026-05-24 — 1,673 candidates total (585 + 354 + 734)

Pre-revision baseline. Catalog cross-match with 1″ radius; uses occupancy-based JWST footprint mask; treats any catalog match as a counterpart regardless of star/galaxy class.

User-identified issues (Points 1–5): footprint vs image data, saturation gate, morphology cuts, mag-dependent PM tolerance, isolated-SN recovery.

v02   built 2026-05-26 — 1,800 candidates total (600 + 600 + 600, top by DAO SNR per category)

From-scratch DAO-photo pipeline on the raw mosaics (programs_star). Per-tile WCS footprints + downsampled pixel-mask intersection (HST F814W ∩ JWST F115W = 0.539 deg2); orphan list restricted to that common region (orphans_v5). Saturated-star veto (saturated_stars_v3 = DAO sat + mag-scaled Gaia bright + per-band 99-pctl peak + local-bright neighbour) removes diffraction-spike contaminants. PM-aware cross-match adds Gaia-DR3-anchored pairs (pairs_*_v4) that the brightness-aware radius misses for high-PM stars over the 19-yr HST→Euclid baseline.

Cutouts: 5″. JWST shown as two RGBs (F115/F150/F277 and F150/F277/F444); Euclid NISP as Y/J/H RGB; HST F814W and Euclid VIS single-band. DAO instrumental magnitudes (AB-calibrated mags coming in v03).

v03   built 2026-05-26 — 1,800 candidates (600 per category) after catalog galaxy veto

Adds catalog FWHM / ellipticity / star-galaxy-flag veto: cross-match each orphan to COSMOS-Web, Euclid MER DR1, HST ACS i-phot, and COSMOS2020 within 0.5″. Any match flagged as galaxy by phz_classification=2, mu_class=1, ACS_MU_CLASS=1, lp_type=0, or with extended morphology (FWHM > 1.5×PSF, ellipticity > 0.30, CW flag_star=False) is dropped. 336,225 v5 orphans → 131,273 v6 orphans (61% galaxy-vetoed).

Uses the original v01 sqrt+ManualInterval color recipe: JWST RGB vmin=1e-4, vmax=center×0.85; Euclid NISP RGB vmin=1e-5, vmax=center×1.2; HST F814W / Euclid VIS single-band grayscale same recipe as v01. Carbon-copy of programs_jwst/03_make_sn_cutouts_jwst.py and programs_euclid/03_make_sn_cutouts_euclid.py.

v06   built 2026-05-27 — 12,136 valid orphan-star candidates inside 0.5414 deg² common region (top 600 shown)

Implements the user's union-of-bands strict rule (2026-05-27):

  • Common region = HST F814W ∩ JWST union (any of F115W/F150W/F277W/F444W) ∩ Euclid bbox = 0.5414 deg² = 1,949 arcmin².
  • HST F814W detection required.
  • JWST detection in AT LEAST ONE of F115W / F150W / F277W / F444W. JWST star_id is the canonical ID (F115W preferred, falls back to F150W, F277W, F444W).
  • Euclid detection in AT LEAST ONE of VIS / NIR-Y / NIR-J / NIR-H.
  • Image-extent veto: HST F814W second-moment FWHM ≤ 0.214″ AND ellip ≤ 0.30.
  • Catalog galaxy veto (Euclid PHZ, HST mu_class, CW flag_star, COSMOS2020 lp_type).

Funnel: 733k HST F814W good+sat → 229,331 in common region → 132,408 with both any-JWST and any-Euclid match → 12,242 after HST image-extent veto → 12,136 after catalog galaxy veto. Top 600 by HST SNR shown in 6 pages. Every thumbnail has a red crosshair at the catalog position.

v05   built 2026-05-26 — superseded by v06. Required F115W detection only; v06 accepts any JWST band.

Implements the user's revised rule (2026-05-26):

  • Must have a JWST F115W detection (JWST star_id is the canonical identifier; no JWST ID → disqualified).
  • Must have HST F814W and Euclid VIS cross-matches — same as v04.
  • JWST chip-gap check: read a 5×5 pixel region at the position from JWST F115W SCI; require ≥ 80 % of pixels finite & nonzero. Removes the F115W_B10_0732664 type of edge artifact.
  • HST image-extent veto (data_properties FWHM/ellip) carried over.
  • Catalog galaxy veto carried over.

Counts: 28,772 3-mission stars → 20,467 after JWST chip-gap veto (8,305 dropped) → 340 after image extent → 336 after catalog galaxy veto. Every thumbnail has a simple red crosshair at the catalog position. Sorted by total proper motion (descending; highest |μ| first).

v04   built 2026-05-26 — superseded by v05. 264 candidates were missing_jwst only; v05 strict rule rejects them.

Implements the user's strict rule (2026-05-26): an orphan STAR candidate must have HST F814W AND Euclid VIS cross-matched detections. The "orphan" character is exclusively a missing JWST F115W cross-match. Detections classified as jwst_only / hst_only / euclid_only in v03 are disqualified because they lack the required HST+Euclid pair.

Additional image-based extent veto: HST F814W second-moment FWHM (data_properties) > 0.21″ or ellipticity > 0.30 → galaxy/artifact. 2,605 candidates met the strict rule → 2,523 after position dedup at 0.05″ → 264 after image-extent veto (89 % were galaxies or artifacts missed by the catalog veto). Catalog galaxy veto + saturated_stars_v3 vetos carried over from v03.
