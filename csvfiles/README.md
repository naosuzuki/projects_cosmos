# csvfiles/ — SN candidate webform index CSVs

This directory holds the **input indexes** that drive the paginated
SN-candidate inspection webforms under `htmls/v01/sn_search/`,
`htmls/v01/orphan_star/`, and the known-SN reference deck
`htmls/v01/known34_index0001.html`.  Each CSV is one ordered list of
sources, with one row per candidate, and is consumed at HTML-rendering
time by the scripts in `programs_webpage/`.

The directory is parallel to `csvfiles_star/` (which holds the
catalog-level data products) and `csvfiles_sn/` (which holds the
CNN-derived candidate catalogs).  Files here are **derived from the v01
master catalog** (`csvfiles_star/v01/master_or_catalog_v01.parquet`)
plus per-source thumbnail PNGs generated by the webpage build.

---

## Naming convention

```
sn_<source_set>_<viewer>_index.csv
```

| Field        | Values                                  | Meaning                                                                        |
| ------------ | --------------------------------------- | ------------------------------------------------------------------------------ |
| `source_set` | `acs_only`, `euclid_only`, `jwst_only`, `known34` | Which sub-population the index covers                                          |
| `viewer`     | `hst`, `jwst`, `euclid`                 | Which mission's thumbnails the webpage will render for these rows              |

So the four source sets × three viewers = 12 production CSVs, plus 3
small test CSVs.

---

## Source sets

| Source set    | What it contains                                                                                          |
| ------------- | --------------------------------------------------------------------------------------------------------- |
| `acs_only`    | Sources detected in **HST/ACS F814W only** — not in JWST or Euclid imaging. Most are SN candidates and historical transients (since they'd appear in the deep modern stacks if they were stars / galaxies). |
| `euclid_only` | Sources detected in **Euclid only** — not in HST or JWST imaging.                                          |
| `jwst_only`   | Sources detected in **JWST only** — not in HST or Euclid imaging.                                          |
| `known34`     | The **34 known SNe** in the COSMOS-Web footprint with previously-published spectroscopic / photometric IDs. Used as a reference set to validate the webform pipeline. |

The "only" sets are filtered down from the v01 master catalog using the
mission-coverage and detection columns, with morphology and SNR cuts
applied upstream.

## Viewers

For a single physical source row, three CSVs may exist in parallel —
one per viewer:

- `sn_<set>_hst_index.csv`   — points the webpage at HST F814W cutouts
- `sn_<set>_jwst_index.csv`  — points at JWST F115/F150/F277/F444W cutouts
- `sn_<set>_euclid_index.csv` — points at Euclid VIS + NISP-Y/J/H cutouts

The webpage stitches the three viewers together so each row of the
deck shows the same source in all three missions side-by-side.

---

## CSV schema

Each row has one source.  Column set varies slightly by viewer:

| Column          | Type | All viewers? | Description                                                       |
| --------------- | ---- | ------------ | ----------------------------------------------------------------- |
| `seq`           | int  | ✓            | Sequence number within the file (drives pagination)               |
| `id`            | int  | ✓            | Source ID (joins back to v01 master)                              |
| `ra`            | float| ✓            | ICRS RA in degrees                                                |
| `dec`           | float| ✓            | ICRS Dec in degrees                                               |
| `mag`           | float| ✓            | AB magnitude in the viewer's primary band                         |
| `tile`          | str  | ✓            | Mission-specific tile identifier                                  |
| `hst_png`       | path | hst viewer   | Relative path to HST F814W thumbnail                              |
| `jwst1_png`     | path | jwst viewer  | Relative path to JWST F115W (or first NIRCam SW) thumbnail        |
| `jwst2_png`     | path | jwst viewer  | Relative path to JWST F444W (or second NIRCam LW) thumbnail       |
| `euclid_vis_png`| path | euclid viewer| Relative path to Euclid VIS thumbnail                             |
| `euclid_nisp_png`| path| euclid viewer| Relative path to Euclid NISP-H (or H-band composite) thumbnail    |

PNG paths are relative to `htmls/` so they resolve correctly when the
deck is loaded as `htmls/v01/sn_search/<deck>/index.html`.

## Pipeline lineage

```
csvfiles_star/v01/master_or_catalog_v01.parquet
            │
            ▼
  programs_webpage/ build script  ────►  csvfiles/sn_<set>_<viewer>_index.csv
            │                              │
            └──────► PNG thumbnails ◄──────┘
                                           │
                                           ▼
                                  htmls/v01/sn_search/<deck>/index.html
                                  htmls/v01/orphan_star/<vNN>/index.html
                                  htmls/v01/known34_index0001.html
```

The PNG thumbnails referenced by each CSV live under
`/Volumes/exdisk1/data/{HST,JWST,Euclid}/COSMOS_*_png/`, exposed in
`htmls/` via the symlinks `htmls/hst → ...`, `htmls/jwst → ...`,
`htmls/euclid → ...`.

## Versioning note

These indexes are all **v01-era** outputs (May 24, 2026; built against
v01 master).  If the upcoming new build (v04) needs an updated set of
candidate indexes, the cleanest path is to create
`csvfiles/v04/sn_<set>_<viewer>_index.csv` files alongside these,
keeping v01 indexes for reproducibility.
